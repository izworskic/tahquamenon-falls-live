# Southern Idaho Decision Network — Product Discovery

This file records adjacent opportunities. It does **not** authorize building all of them inside Shoshone Falls Live.

## 1. Shoshone Falls Live — built

**Intent:** Is Shoshone Falls flowing today, what will it look like, and is it worth my trip?

**Decision:** go now / verify visually / wait / pair with another nearby experience.

**Primary personas:** Twin Falls visitor, I-84 road tripper, dedicated waterfall traveler, photographer, family, limited-mobility visitor.

**JEV role:** bounded ranking of practical daylight/weather windows and persona-fit choices.

## 2. Perrine Bridge Live — strong future candidate

**Intent:** What is happening at Perrine Bridge right now and when is the best time to see the canyon/bridge activity?

**Possible sources:** official/public bridge camera where rights permit, NWS wind/visibility, daylight/solar geometry, road/context sources.

**Personas:** road trippers, photographers, canyon visitors, spectators.

**Seasonality:** year-round, with weather/light changing the experience.

**JEV role:** rank supplied viewing/photo windows. Never give individualized BASE-jump safety approval or imply conditions make a jump safe.

**Relationship to Shoshone:** short Twin Falls add-on when waterfall flow is weak or the visitor has extra time.

## 3. Thousand Springs Today — strong future candidate

**Intent:** Which Thousand Springs State Park unit should I visit today?

**Problem:** the park is geographically distributed and units/access/activities vary by season.

**Possible sources:** Idaho Parks & Recreation unit/access information, NWS weather, daylight, water context where meaningful.

**Personas:** families, hikers, waterfall/scenic visitors, paddlers, road trippers.

**JEV role:** rank only validated open/available units against visitor time and interests.

**Relationship to Shoshone:** regional half-day/full-day extension, not a distraction from strong Shoshone conditions.

## 4. Twin Falls Canyon Day Planner — later synthesis layer

**Intent:** I have 2/4/6 hours in Twin Falls; what should I actually do?

**Candidate inventory:** Shoshone Falls, Dierkes Lake, Perrine Bridge, Canyon Rim, Centennial Waterfront, Perrine Coulee and other validated stops.

**JEV role:** itinerary ranking from a closed destination inventory with deterministic drive/walk/time budgets.

**Do not build until:** the strongest individual destination surfaces have proven user value.

## Cross-link rule

Cross-pollination must be contextual:

- weak/uncertain Shoshone + nearby family → Dierkes Lake;
- extra Twin Falls time → Perrine Bridge/canyon;
- half/full regional day → Thousand Springs.

Do not build a generic "more tools" footer and call that network intelligence.
